候选来源

每个地址都要是公开可访问的 txt。每行可以是 1.1.1.1、1.1.1.0/24、 1.1.1.1:443、1.1.1.1:443#备注，也可以是域名 （www.shopify.com:443#企业域名，会自动 DNS 解析成 IP）；# 开头为注释。 多个地址里的同一 IP 只会测一次。

筛选参数

实测这台 NAS 到 LAX 约 204~209ms，阈值设 200 会一条结果都没有
官方默认的 cf.xiu2.xyz 在这条线路返回 403
从延迟最低的 IP 里取这么多个测下载速度；并行下载数是同时测几个（1~32）。 并发越高越省时间，但几个 IP 抢同一条带宽，测出的速度会偏低——要准确数值就设 1。

输出后缀

源列表每行自带的 #备注（如 #企业域名 | OpenAI）会原样作为后缀；没有备注时回退到数据中心码
可用占位符：{colo} 数据中心 · {latency} 延迟 · {speed} 速度
